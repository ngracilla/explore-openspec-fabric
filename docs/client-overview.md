### Agent involvement levels

This is the single source for the involvement levels. Other documents link here and do not restate them. The levels apply to the reader's Fabric repository.

| Level | Agents may | Humans do | Needs |
|---|---|---|---|
| 1. Suggest only | Propose tests in conversation | Write and run everything | Nothing |
| 2. Tests local (recommended starting point) | Write all tests and run the local ones | Place all production code; run the in-Fabric tests | Nothing in Fabric |
| 3. Tests including dev workspace | As level 2, plus run in-Fabric tests against a dev workspace | Place all production code; review changes | A read-only identity on the dev workspace |
